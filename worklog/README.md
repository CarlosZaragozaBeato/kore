# Worklog de Kore

Este directorio guarda el historial de implementaciones, avances, problemas y decisiones técnicas del proyecto. Crear una entrada por día o por cambio relevante con el nombre `AAAA-MM-DD-tema.md`.

Cada entrada debe indicar:

- Estado y objetivo.
- Cambios realizados y motivo.
- Verificación y resultado observable.
- Problemas abiertos, decisiones y siguiente paso.

Actualizar la entrada pertinente cuando un problema quede resuelto. No copiar secretos, tokens, datos de salud, ubicaciones ni exportaciones personales. Referenciar rutas de código y documentación en lugar de incluir datos sensibles.
